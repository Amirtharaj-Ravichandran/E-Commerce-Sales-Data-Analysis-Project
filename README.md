# E-Commerce-Sales-Data-Analysis-Project
Analyzed e-commerce sales data using Excel, applying data cleaning, formulas, descriptive statistics, PivotTables, and interactive dashboards. Created charts to identify sales trends, regional performance, payment preferences, and product insights, supporting data-driven business decisions.
Dataset Description:
This dataset has 500 rows and 8 columns. It contains details about e-commerce sales such as orders, customers, products, prices, discounts, payment methods, and total amount.

Column Description
Column Name	Description
CUSTOMER ID -It represents customer id in each transaction.
STORE ID -	It represents Store ID in each transaction.
PRODUCT ID	- It represents Product ID in each Transaction.
CATEGORY	- It represents Category of the Product
SUB CATEGORY	- It represents the Type of the Product
BRAND	- It represents the Brands of the Product
REGION -	It represents the Region of sales
STORE TYPE	- It represents the what type of store
PAYMENT TYPE	- It represents type of the payment
STORE CITY	- It represents the location of the store
UNIT PRICE	- It represents Price of the Product with Discount
Total Amount	- It represents Total Price after Discount
